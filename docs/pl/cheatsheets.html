Typ nTyp p

  • Złącze p-n: dyfuzja → rekombinacja → obszar zubożony → bariera potencjału.
  • Przewodzenie: „+” na p (anoda), „−” na n (katoda). Zaporowo: odwrotnie — prąd nie płynie.

Dioda

  • Przewodzi od anody do katody, gdy napięcie przekroczy próg: krzemowa ≈ 0,6 V; LED czerwona ≈ 2 V ✚.
  • LED: dłuższa nóżka = anoda (+). Zawsze z rezystorem: R = Uzas − ULEDI ✚.

Tranzystor bipolarny

  • Końcówki: Emiter, Baza, C (kolektor). Strzałka = emiter. NPN: strzałka na zewnątrz, PNP: do środka.
  • Mały prąd bazy steruje dużym prądem kolektora: IC = β · IB, β > 100.
  • Włącza się, gdy UBE ≈ 0,6 V (złącze B–E w kierunku przewodzenia).
  • Charakterystyki: wejściowa IB(UBE), wyjściowa IC(UCE), przejściowa IC(IB) — liniowa.
  • Jako klucz ✚: brak prądu bazy → zatkany (wyłączony); duży prąd bazy → nasycony (włączony).

Tranzystory polowe

  • Końcówki: S (źródło), D (dren), G (bramka). Sterowane napięciem bramki, prąd bramki ≈ 0.
  • JFET: bramka zwęża kanał. gm = dIDSdVGS.
  • MOSFET: bramka izolowana tlenkiem; podstawa układów cyfrowych (CMOS).

Wykład 5. Wzmacniacze operacyjne

Wzmacniacz operacyjny

  • Wzmacnia różnicę: Vout = k · (V+ − V−), k ogromne (10⁵…10⁷).
  • Ideał: k = ∞, Zin = ∞, Zout = 0, prąd wejściowy 0, offset 0.
  • Wyjście nie wyjdzie poza zasilanie (nasycenie). Pasmo × wzmocnienie = const.
  • ✚ Przy ujemnym sprzężeniu: do wejść nie płynie prąd oraz V+ = V−.

Wykład 6. Układy cyfrowe — wprowadzenie: sygnały, bramki, algebra Boole'a

Poziomy logiczne

  • TTL (5 V, tranzystory bipolarne): 0 → 0–0,8 V; 1 → 2–5 V; pomiędzy — nieokreślony.
  • CMOS (3–18 V, pary MOS): 0 → 0–30% zasilania; 1 → 70–100%; moc tylko przy przełączaniu.
  • Hi-Z — trzeci stan (nic nie podłączone); ustala się go rezystorem podciągającym (pull-up).

Algebra Boole'a

  • a + a = 1, a · a = 0, a + ab = a, a(a+b) = a
  • a(b+c) = ab + ac, a + bc = (a+b)(a+c)
  • De Morgan: a + b = a · b, a · b = a + b
  • Sklejanie: ab + ab = a

Postacie kanoniczne

  • Sumacyjna (DNF), Σ: z wierszy z 1; iloczyn zmiennych, 0 → negacja; iloczyny łączymy „+”.
  • Iloczynowa (CNF), Π: z wierszy z 0; suma zmiennych, 1 → negacja; sumy łączymy „·”.
  • Numer wiersza = wartość dziesiętna bitów wejściowych.

Z samych NAND

NOT a = a·a; a AND b = a·b; a OR b = a·b

Z samych NOR

NOT a = a+a; a OR b = a+b; a AND b = a+b

Wykład 7. Minimalizacja funkcji boolowskich: mapy Karnaugha

Mapa Karnaugha — procedura

  1. Narysuj mapę; kolumny i wiersze w kodzie Graya: 00, 01, 11, 10.

Na NAND / NOR

Wykład 8. Kombinacyjne bloki funkcjonalne: multiplekser, kod U2, sumator, ALU

Multiplekser

  • n wejść adresowych → 2n wejść informacyjnych; wyjście = wejście o numerze podanym na adresie.
  • Funkcja na MUX 16:1: na wejścia o numerach z listy Σ podaj 1, na resztę 0.
  • Funkcja na MUX 8:1: 3 zmienne na adres, czwarta „wolna” x. Dla każdego adresu porównaj y przy x = 0 i x = 1:
y(x=0), y(x=1)0, 01, 10, 11, 0
na wejście01xx
  • Wolna x3: pary wierszy (k, k+8). Wolna x0: pary (2k, 2k+1).
  • DMUX: jedno wejście → wyjście wskazane adresem. Dekoder: NKB → 1 z N.

Kod U2 (N bitów)

  • Waga najstarszego bitu: −2N−1. Zakres: −2N−1 … 2N−1−1 (4 bity: −8…7; 8 bitów: −128…127).
  • Liczba przeciwna: zaneguj bity, dodaj 1.
  • Dodawanie jak w NKB; przeniesienie z MSB ignoruj. Odejmowanie: a + (−b).
  • Overflow = CIN ⊕ COUT najstarszego bitu (dodatnia + dodatnia = ujemna albo odwrotnie).

Sumator i ALU

  • Sumator pełny: y = a ⊕ b ⊕ c0, c = ab + ac0 + bc0. Sumator n-bitowy = kaskada.
  • Półsumator (bez przeniesienia wejściowego) ✚: s = a ⊕ b, c = ab.
  • ALU: A, B — dane; F — kod operacji; R — wynik; D — flagi. Wszystkie operacje liczone naraz, MUX wybiera wynik.
  • Inne kody: BCD (cyfra → 4 bity), ZM (bit znaku + moduł), U1 (negacja bitów), Gray, 1 z N.

Wykład 10. Projektowanie synchronicznych układów sekwencyjnych

Procedura (automat Moore'a, przerzutniki D)

  1. Stany i wyjścia — wypisz, co ma być na wyjściach w każdym stanie.
  2. Graf / tabela przejść — dla każdego stanu i każdej kombinacji wejść: następny stan.
  3. Kodowanie — n przerzutników, 2n ≥ liczba stanów; kody najlepiej w kolejności Graya (00, 01, 11, 10).
  4. Tabela zakodowana — zamiast nazw stanów wpisz kody.
  5. Funkcje wzbudzeń — dla przerzutnika D: Di = i-ty bit następnego stanu. Mapa Karnaugha ze zmiennymi: bity stanu + wejścia.
  6. Funkcje wyjść — mapa Karnaugha tylko ze zmiennych stanu (Moore).
  7. Układ — przerzutniki na wspólnym zegarze + bramki.

Do zapamiętania

  • Moore: wyjście = f(stan) — wartości w kółkach. Mealy: wyjście = f(stan, wejście) — wartości przy strzałkach.
  • Z każdego stanu musi wychodzić strzałka dla każdej kombinacji wejść.
  • Kodowanie — kody różniące się 1 bitem dla: (1) stanów o tym samym stanie następnym, (2) stanów następnych tego samego stanu, (3) stanów o tych samych wyjściach.
  • Stany równoważne: te same wyjścia + stany następne takie same lub równoważne → łączymy w jeden.
  • Kratki nieokreślone (kody nadmiarowe, niemożliwe wejścia) — wpisz, co wygodne.
  • Przydatne: XOR = ab + ab; układ wzorów często upraszcza się do XOR/AND/NOT.

Wykład 11. Systemy komputerowe, mikroprocesory i mikrokontrolery

Komputer

  • Von Neumann: procesor (z ALU) + pamięć (dane i program razem) + wejście/wyjście; rozkazy wykonywane po kolei.
  • Harvard: osobna pamięć programu i danych (mikrokontrolery: Flash + RAM).
  • Cykl rozkazowy: pobranie → dekodowanie → wykonanie.
  • Rejestry: PC (adres następnego rozkazu), rejestr rozkazów, akumulator, SP (stos), rejestr flag.
  • Magistrale: adresowa, danych, sterująca.
  • CISC: dużo złożonych rozkazów, zmienny czas. RISC: mało prostych rozkazów, jeden cykl, potokowość.

Mikrokontroler

µC = procesor + RAM + pamięć programu + porty I/O + peryferia (UART, SPI, I²C, ADC, timery, watchdog) w jednym układzie.

Programowanie: programator wysokonapięciowy / ISP / bootloader (Arduino).

Wykład 13. Peryferia mikrokontrolerów i obsługa zdarzeń

Piny i PWM

  • pinMode(pin, OUTPUT / INPUT / INPUT_PULLUP); max 40 mA na pin; wyjścia nie zwierać do masy ani zasilania.
  • PWM: wypełnienie ω = τT; średnie napięcie = wypełnienie × 5 V. Arduino: analogWrite(pin, 0…255), ok. 490 Hz.
  • Serwo: impuls co 20 ms (50 Hz); 1,5 ms = pozycja neutralna (90°).
  • ADC: 10 bitów → 0…1023; U = odczyt · 51023 ✚. Wyjście „analogowe” = PWM + filtr.

Tranzystor jako klucz

  • Zatkanie (brak prądu bazy) = wyłączony; nasycenie (duży prąd bazy) = włączony.
  • Mostek H: S1+S4 → jeden kierunek, S2+S3 → przeciwny; prędkość — PWM.

Przetworniki

  • DAC z rezystorami ważonymi: wzmacniacz operacyjny jako sumator prądów.
  • ADC flash: 2n − 1 komparatorów, bardzo szybki, mało bitów.
  • ADC kompensacyjny: n porównań dla n bitów (najpierw z połową zakresu).

Wykład 14. Architektura komputerów: procesor MIPS od środka

Pojęcia

  • Architektura = zestaw instrukcji + stan (rejestry, pamięć). Mikroarchitektura = sposób realizacji sprzętowej.
  • Ścieżka danych (PC, pamięci, plik rejestrów, ALU, multipleksery) + jednostka sterująca (sygnały dla ścieżki).
  • Czas programu = liczba instrukcji × cykle/instrukcję × sekundy/cykl.

Ćwiczenie 1. Zajęcia wstępne: sprzęt w laboratorium

Multimetr

  • Czarny przewód zawsze w COM. Czerwony: VΩ (napięcie, opór) albo mA / 20A (prąd).
