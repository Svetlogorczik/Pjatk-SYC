Минимизация булевых функций: карты Карно

Одна и та же функция может требовать десять вентилей или три. Карта Карно — способ найти короткий вариант без угадывания, а потом собрать его из одних NAND или NOR.

Суммарная форма (по одному произведению на каждую единицу — см. лекцию 6):

y = abc + abc + abc

Реализованная «в лоб», она требует трёх инверторов, трёх 3-входовых вентилей AND и вентиля OR. Можно ли меньше?

Преобразование формулы

Пользуясь законами булевой алгебры, формулу можно упрощать:

abc + abc + abc = abc + ab(c + c) = abc + ab

(потому что c + c = 1). На лекции показано и дальнейшее преобразование к виду (ab + ab)(a + b + c). Все эти формулы описывают одну и ту же функцию — они эквивалентны, значит, эквивалентны и их схемы.

Зачем минимизировать? Чтобы схема была дешевле. Можно стремиться к:

  • меньшему числу вентилей,
  • меньшему числу входов вентилей,
  • меньшему разнообразию вентилей (например, только NAND),
  • меньшему времени проектирования.

Преобразовывать «вручную» долго, и легко что-то упустить. Отсюда карты Карно.

Код Грея

000 → 001 → 011 → 010 → 110 → 111 → 101 → 100

В коде Грея два соседних слова отличаются только одним битом. Это относится и к последнему с первым (код циклический). Для двух битов: 00, 01, 11, 10 — это нужно знать наизусть.

Правило склеивания

a · f + a · f = (a + a) · f = f

Если два произведения отличаются только одной переменной (в одном она с отрицанием, в другом без), их можно заменить одним — без этой переменной. Пример: abc + abc = ab.

И здесь нужен код Грея: если строки таблицы расположить в порядке Грея, то произведения, которые можно склеить, окажутся рядом.

Карта Карно

Карта Карно (mapa Karnaugha) — это таблица истинности, нарисованная в виде прямоугольника, в котором строки и столбцы подписаны в порядке кода Грея. Каждая клетка — одна строка таблицы истинности.

Наша функция на карте (a в строках, bc в столбцах):

a \ bc00011110
00010
11100

⚠️Внимание

Столбцы идут в порядке 00, 01, 11, 10, а не 00, 01, 10, 11. Самая частая ошибка на занятиях — вписать значения из строк 2 и 3 таблицы истинности не в те столбцы.

Группировка единиц → суммарная форма

Правила из лекции:

  1. Группируем единицы, соседние по горизонтали или вертикали, в количестве, равном степени двойки (1, 2, 4, 8…).
  2. Из каждой группы получается одно произведение. Выбрасываем переменную, которая в группе меняется; остаются постоянные.
  3. Постоянная переменная, равная 1, входит без отрицания, равная 0 — с отрицанием.

Для нашей карты:

  • группа из двух единиц в строке a = 1, столбцы 00 и 01: меняется c, постоянны a = 1 и b = 0 → ab,
  • одинокая единица в клетке a = 0, bc = 11 → abc.
y = ab + abc

Группировка нулей → мультипликативная форма

То же самое, но группируем нули, и из каждой группы получается сумма. Меняющуюся переменную выбрасываем, а остальные инвертируем (переменная, равная 0, входит без отрицания, равная 1 — с отрицанием).

  • нули в строке a = 0, столбцы 00 и 01: постоянны a = 0, b = 0 → (a + b),
  • нули в столбце 10 (обе строки): постоянны b = 1, c = 0 → (b + c),
  • нули в строке a = 1, столбцы 11 и 10: постоянны a = 1, b = 1 → (a + b).
y = (a + b) · (b + c) · (a + b)

Обе формы эквивалентны — если раскрыть скобки и упростить, получится ab + abc.

✚Правила группировки, о которых легко забыть

На слайде есть только правило «по вертикали или горизонтали, в количестве, равном степени двойки». На практике (и на лабораторной с функцией 4 переменных) нужны ещё:

  • Группа должна быть прямоугольником: 1×2, 2×2, 1×4, 2×4… (не «Г», не по диагонали).
  • Края карты соприкасаются: левый столбец соседствует с правым, верхняя строка — с нижней. Четыре угла тоже могут образовать одну группу.
  • Группы должны быть как можно больше (больше группа = короче произведение), а самих групп — как можно меньше.
  • Группы могут пересекаться — единицу можно использовать много раз.
  • Каждая единица должна попасть хотя бы в одну группу.
  • Группа из 2 клеток убирает 1 переменную, из 4 клеток — 2 переменные, из 8 клеток — 3 переменные.

🔎✚ Собственный пример: функция четырёх переменных

y = Σ(0, 1, 2, 5, 8, 9, 10), переменные a, b, c, d (строка = ab, столбец = cd):

ab \ cd00011110
001101
010100
110000
101101

Номера клеток: строка 00 → 0, 1, 3, 2; строка 01 → 4, 5, 7, 6; строка 11 → 12, 13, 15, 14; строка 10 → 8, 9, 11, 10.

Группы:

  1. клетки 0, 1, 8, 9 — строки 00 и 10 (верхняя и нижняя соприкасаются), столбцы 00 и 01. Постоянны: b = 0, c = 0 → bc
  2. клетки 0, 2, 8, 10 — четыре угла. Постоянны: b = 0, d = 0 → bd
  3. клетки 1 и 5 — столбец 01, строки 00 и 01. Постоянны: a = 0, c = 0, d = 1 → acd
y = bc + bd + acd

Вместо 7 произведений по 4 переменные — три коротких.

Реализация только на вентилях NAND

Берём суммарную форму, инвертируем её дважды (ничего не меняется) и «внутреннее» отрицание раскрываем по закону де Моргана:

y = ab + abc = ab + abc = ab · abc

Каждое произведение с чертой — это вентиль NAND, а черта над всем выражением — ещё один NAND. На практике: схема «сначала AND, потом OR» превращается в «сначала NAND, потом NAND» с той же структурой. Отрицания отдельных переменных тоже делаются вентилем NAND с соединёнными входами.

Реализация только на вентилях NOR

Берём мультипликативную форму и делаем то же самое:

y = (a+b)(b+c)(a+b) = (a+b) + (b+c) + (a+b)

Схема «сначала OR, потом AND» превращается в «сначала NOR, потом NOR».

💡Короткая памятка

Нужен NAND → группируй единицы (суммарная форма). Нужен NOR → группируй нули (мультипликативная форма). Потом двойное отрицание и де Морган.

🎓Задания на лабораторную (со слайда)

  1. Для функции четырёх переменных, заданной преподавателем (у каждого своя), реализовать на вентилях NAND её минимальную форму.
  2. Только на вентилях NOR реализовать управление мобильным роботом с тремя датчиками препятствий и двумя моторами.

Карта Карно — порядок действий

  1. Нарисуй карту; столбцы и строки в коде Грея: 00, 01, 11, 10.
  2. Впиши значения из таблицы истинности (следи за порядком столбцов!).
  3. Отметь группы: прямоугольники по 1, 2, 4, 8 клеток; как можно больше по размеру, как можно меньше по числу; могут пересекаться; края и углы соприкасаются ✚.
  4. Для каждой группы: выбрось переменные, которые меняются, запиши постоянные.

На NAND / NOR

  • NAND: суммарная форма → двойное отрицание → де Морган: ab + cd = ab · cd
  • NOR: мультипликативная форма → двойное отрицание → де Морган: (a+b)(c+d) = a+b + c+d
  • Склеивание: a·f + a·f = f. Код Грея (3 бита): 000, 001, 011, 010, 110, 111, 101, 100.
