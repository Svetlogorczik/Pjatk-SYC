Комбинационные функциональные блоки: мультиплексор, дополнительный код, сумматор, АЛУ

Функциональный блок

Комбинационный функциональный блок — это комбинационная схема с n входами и m выходами. Булева функция — его частный случай с одним выходом.

Примеры: коммутационные схемы (мультиплексоры, демультиплексоры, дешифраторы, преобразователи кодов) и арифметические (сумматоры, компараторы).

Мультиплексор (MUX)

У мультиплексора есть:

  • n адресных входов (выбирающих),
  • N = 2n информационных входов (данных),
  • один выход,
  • вход разрешения enable (обычно: e = 1 — работает, e = 0 — выключен).

Он работает как переключатель: на выход попадает сигнал с того информационного входа, номер которого подан на адресные входы.

🧒По-простому

Мультиплексор — это пульт от телевизора. Информационные входы — каналы, адресные входы — номер канала, нажатый на пульте, а выход — то, что видно на экране. (Это сравнение взято из материалов к занятиям.)

  • Число информационных входов растёт экспоненциально, поэтому большие мультиплексоры не строят напрямую — их собирают из меньших (каскадом).
  • Групповой мультиплексор переключает целые слова (например, 4-битные шины A и B), а не отдельные биты.

Демультиплексор (DMUX) и дешифратор

Демультиплексор работает наоборот: один информационный вход, n адресных входов и N = 2n выходов. Сигнал со входа попадает на тот выход, на который указывает адрес.

Дешифратор (dekoder) — это демультиплексор, у которого вход постоянно равен 1: он превращает двоичное число (NKB) в код «1 из N» — активен ровно один выход.

Мультиплексор как логическая функция

На мультиплексоре можно реализовать любую булеву функцию. Пример из лекции: y = Σ(1, 7, 11, 13, 14, 15), переменные x3 x2 x1 x0.

Способ 1: мультиплексор с 4 адресными входами (16 входов)

Все четыре переменные идут на адресные входы. На информационные входы с номерами 1, 7, 11, 13, 14, 15 подаём 1, на остальные — 0. Мультиплексор просто «читает таблицу истинности».

Способ 2: мультиплексор с 3 адресными входами (8 входов)

Три переменные идут на адрес, а четвёртая — на информационные входы. Для каждого адреса сравниваем два значения функции (при четвёртой переменной, равной 0 и 1):

Функция при «свободной» переменной x = 0 / x = 1Что подать на вход

1 / 0x

Вариант A — адрес x2 x1 x0, свободная переменная x3 (сравниваем строки k и k + 8):

Способ 3: мультиплексор с 2 адресными входами (4 входа)

Адрес — x3 x2, а на каждый вход подаём функцию переменных x1, x0, считанную с одной строки карты Карно:

NKB

значение = Σ 2i · bi

Биты нумеруются с нуля справа; веса — 1, 2, 4, 8, 16, 32, 64, 128. На N битах — 2N разных значений (8 бит: 0…255).

Прямой и обратный код

  • ZM: −24 = 1 0011000, 118 = 0 1110110. Диапазон ±(2N−1 − 1). Недостаток: два нуля (+0 и −0).
  • U1: положительные числа как в ZM; отрицательные — с инвертированными битами модуля: −86 в ZM — 11010110, в U1 — 10101001. Тоже два нуля.

Дополнительный код (U2) — тот, которым на самом деле пользуются компьютеры

У старшего бита вес отрицательный, у остальных — положительный:

значение = −2N−1 · bN−1 + Σ 2i · bi
  • Диапазон: от −2N−1 до 2N−1 − 1 (8 бит: −128…127; 4 бита: −8…7).
  • У нуля только одно представление; код полный (2N значений).
  • Положительные числа выглядят так же, как в NKB.
  • Старший бит говорит о знаке: 1 = отрицательное.

4-битные примеры из материалов к занятиям: 1111 = −8+4+2+1 = −1, 1000 = −8, 0111 = 7.

Противоположное число: инвертируй все биты и прибавь 1.

7 = 00000111  →  11111000  →  +1  →  11111001 = −7

🧒По-простому

Одометр в машине, который ты скручиваешь назад. С 0000 шаг назад даёт 9999 — и мы договариваемся, что 9999 значит «−1». В дополнительном коде то же самое, только в двоичной системе: 0000 − 1 = 1111, то есть −1.

Сложение и вычитание в U2

  • Складываем так же, как в NKB, не глядя на знаки.
  • Перенос из старшего бита игнорируем.
  • Вычитание — это прибавление противоположного числа: a − b = a + (−b). Значит, хватит отрицания и сумматора.
ДействиеЗаписьРезультат
25 + (−1)00011001 + 11111111(1) 00011000 = 24 ✓
25 + (−56)00011001 + 1100100011100001 = −31 ✓
(−25) + (−56)11100111 + 11001000(1) 10101111 = −81 ✓
112 + 11301110000 + 0111000111100001 = «−31» ✗ переполнение
(−75) + (−56)10110101 + 11001000(1) 01111101 = «+125» ✗ переполнение

Переполнение (przekroczenie zakresu, overflow) возможно только когда складываем два положительных или два отрицательных числа, а результат «не помещается». Это видно по знаку: из двух положительных вышло отрицательное или наоборот.

Аппаратное обнаружение: смотрим на два переноса у старшего бита — входящий (CIN) и выходящий (COUT). Переполнение есть тогда и только тогда, когда они различаются:

OFL = CIN ⊕ COUT

Другие ловушки U2: диапазон несимметричен (для 8 бит −128 есть, а +128 нет), а увеличение 127 на 1 даёт −128.

Числа с дробной частью

  • С фиксированной точкой: договариваемся, что часть битов — целая часть, остальные — дробная. Например, 5 + 3 бита в U2 — веса: −16, 8, 4, 2, 1, ½, ¼, ⅛. Тогда 11001110 = −16 + 8 + 1 + ½ + ¼ = −6¼. Диапазон: от −16 до 15⅞, точность ⅛.
  • С плавающей точкой: мантисса · 2порядок.

При конечном числе битов некоторые числа записываются с ошибкой, а иррациональные — всегда.

Сумматор

Сложение столбиком в двоичной системе:
7601001100
+ 11801110110
= 19411000010

В каждом разряде складываем три бита: ai, bi и перенос ci из предыдущего разряда; получаем бит суммы и перенос дальше. Это делает одноразрядный (полный) сумматор:

y = a ⊕ b ⊕ c0  c = ab + ac0 + bc0

n-разрядный сумматор — это каскад одноразрядных: перенос из одного входит в следующий.

Для чисел без знака перенос из старшего бита (cn = 1) означает, что результат не поместился: 152 + 118 = 270 на 8 битах даёт 00001110 (= 14) и перенос 1. Его можно считать дополнительным, старшим битом результата.

✚От автора сайта (не из лекции)

На слайде в этом примере сложения опечатка: второе слагаемое подписано «188», а запись 01110110 — это 118 (76 + 118 = 194).

Компаратор и АЛУ

Компаратор сравнивает два n-разрядных числа и сообщает, A < B, A = B или A > B.

АЛУ (ALU, Arithmetic Logic Unit, арифметико-логическое устройство) — это комбинационная схема, которая выполняет арифметические и логические операции над двумя числами (или над одним).

  • A, B — входные данные,
  • F — код операции (что считать),
  • R — результат,
  • D — статус, то есть флаги (например, результат равен нулю, переполнение).

Простейшая реализация: все операции считаются одновременно, а мультиплексор, управляемый кодом F, выбирает, какой результат попадёт на выход.

  3. Схема, обнаруживающая переполнение для 4-битных чисел в U2.
  4. 4-битное АЛУ с четырьмя операциями (на слайде: 00 ADD, 01 NEG, 10 XOR, 11 AND) и флагами Z (результат ноль) и C (переполнение).

Мультиплексор

  • n адресных входов → 2n информационных; выход = вход с номером, поданным на адрес.
  • Функция на MUX 16:1: на входы с номерами из списка Σ подай 1, на остальные 0.
  • Функция на MUX 8:1: 3 переменные на адрес, четвёртая «свободная» x. Для каждого адреса сравни y при x = 0 и x = 1:
y(x=0), y(x=1)0, 01, 10, 11, 0
на вход01xx
  • Свободная x3: пары строк (k, k+8). Свободная x0: пары (2k, 2k+1).
  • DMUX: один вход → выход, указанный адресом. Дешифратор: NKB → 1 из N.

Дополнительный код U2 (N бит)

  • Вес старшего бита: −2N−1. Диапазон: −2N−1 … 2N−1−1 (4 бита: −8…7; 8 бит: −128…127).
  • Противоположное число: инвертируй биты, прибавь 1.
  • Сложение как в NKB; перенос из старшего бита игнорируй. Вычитание: a + (−b).
  • Переполнение = CIN ⊕ COUT старшего бита (положительное + положительное = отрицательное или наоборот).

Сумматор и АЛУ

  • Полный сумматор: y = a ⊕ b ⊕ c0, c = ab + ac0 + bc0. n-разрядный сумматор = каскад.
  • Полусумматор (без входного переноса) ✚: s = a ⊕ b, c = ab.
  • АЛУ: A, B — данные; F — код операции; R — результат; D — флаги. Все операции считаются сразу, MUX выбирает результат.
  • Другие коды: BCD (цифра → 4 бита), ZM (бит знака + модуль), U1 (инверсия битов), Грея, 1 из N.
