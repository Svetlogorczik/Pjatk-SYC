Лекция 15

Ассемблер и архитектура компьютеров (MIPS)

Язык, на котором на самом деле «говорит» процессор. Команды, регистры, память, переходы и циклы на ассемблере MIPS — и как такая команда выглядит в виде 32 нулей и единиц.

✚ = добавлено автором сайта — этого нет ни в слайдах, ни в записи лекции

Язык компьютера

  • Слова в языке компьютера — это команды (инструкции), а его словарь — набор команд.
  • Все программы, работающие на данном компьютере, используют один и тот же набор команд.
  • Команды закодированы двоичными числами — это машинный язык.
  • Удобнее записывать их символически — это ассемблер (assembly).

Одна строка кода высокого уровня и её аналог в MIPS:

  • add — мнемоника: говорит, какую операцию выполнить,
  • b и c — операнды-источники, a — операнд-приёмник (результат).
  • Комментарий начинается с # и идёт до конца строки.

Более сложное выражение нужно разбить на несколько команд: a = b + c − d — это sub t, c, d и add a, b, t.

🧒По-простому

Ассемблер — это рецепт, расписанный на самые мелкие шаги: «возьми яйцо», «разбей яйцо», «вылей в миску». Никакого «сделай омлет» — процессор знает только такие отдельные движения.

Регистры

Команды работают с регистрами — быстрыми ячейками внутри процессора. В MIPS их 32 (Register File). Имена начинаются с $.

РегистрыНомераДля чего
$00всегда содержит ноль
$v0–$v12–3значение, возвращаемое функцией
$a0–$a34–7аргументы функции
$t0–$t78–15временные (temporary) — промежуточные результаты
$s0–$s716–23сохраняемые (saved) — переменные программы
$sp29указатель стека
$ra31адрес возврата из функции

Память

Регистров всего 32, поэтому большинство данных лежит в памяти. Для переноса данных есть две команды:

  • lw (load word) — загрузить слово из памяти в регистр,
  • sw (store word) — записать слово из регистра в память.

Адрес записывается как смещение(базовый регистр): lw $s3, 8($t0) значит «возьми слово по адресу $t0 + 8».

  • Память MIPS адресуется байтами: у каждого байта свой адрес.
  • Слово — это 32 бита = 4 байта, поэтому адреса соседних слов кратны 4: 0, 4, 8, 12…

Big-endian и little-endian

Это два способа нумерации байтов в слове. В big-endian байт номер 0 находится на «большом» (старшем) конце; в little-endian — на «малом» (младшем).

Константы (непосредственные значения)

Константа, записанная прямо в команде, называется непосредственной (immediate) — за ней не нужно обращаться ни к регистру, ни к памяти. Для этого служит addi (прибавить константу).

Машинный язык: три формата

Каждая команда MIPS занимает ровно 32 бита. Форматов три:

ФорматПоля (число бит)Для чего
R (register)op (6) · rs (5) · rt (5) · rd (5) · shamt (5) · funct (6)операции над тремя регистрами
I (immediate)op (6) · rs (5) · rt (5) · imm (16)два регистра и 16-битная константа
J (jump)op (6) · addr (26)переходы

Тип R

  • rs, rt — регистры-источники, rd — регистр-приёмник,
  • у всех команд типа R op = 0; какая это операция, определяет поле funct,
  • shamt — на сколько бит сдвигать (только в командах сдвига).

🔎Пример из лекции: add $t0, $s4, $s5

В ассемблере первым идёт регистр-приёмник; в машинном коде порядок полей другой: rs, rt, rd.

Полеoprs ($s4)rt ($s5)rd ($t0)shamtfunct (add)
В десятичной020218032
В двоичной00000010100101010100000000100000

Вместе: 0000 0010 1001 0101 0100 0000 0010 0000 = 0x02954020. Проще всего сначала записать в двоичном виде, а потом группировать по 4 бита в шестнадцатеричные цифры.

Тип I

🔎Пример из лекции: lw $s3, −24($s4)

Полеop (lw)rs ($s4)rt ($s3)imm
В десятичной352019−24
В двоичной10001110100100111111 1111 1110 1000

Вместе: 0x8E93FFE8. Число −24 записано в дополнительном коде на 16 битах (лекция 8).

Тип J

Используется только для переходов: 6 бит кода операции и 26 бит адреса.

В обратную сторону: из машинного кода в ассемблер

Первые 6 бит — это opcode: он говорит, как читать остальное.

🔎Пример из лекции

0x2237FFF1 = 001000 10001 10111 1111111111110001 → op = 8 (addi), rs = 17 ($s1), rt = 23 ($s7), imm = −15 → addi $s7, $s1, -15

0x02F34022 = 000000 10111 10011 01000 00000 100010 → op = 0 (тип R), rs = 23 ($s7), rt = 19 ($s3), rd = 8 ($t0), funct = 34 (sub) → sub $t0, $s7, $s3

Программа в памяти

Программа на машинном языке — это просто последовательность двоичных чисел, хранящаяся в памяти, так же как данные. Счётчик команд PC указывает на команду, которая сейчас выполняется.

Логические команды и сдвиги

  • Логические: and, or, xor, nor — работают побитно с двумя регистрами. Варианты с константой: andi, ori.
  • Сдвиги: sll (логический влево), srl (логический вправо), sra (арифметический вправо).
  • Сдвиг на n бит — это умножение или деление на 2n: sll $t0, $t0, 3 умножает на 8.

Переходы и ветвления

Сила компьютера в том, что он умеет принимать решения.

КомандаЗначение
beq rs, rt, меткаперейти, если регистры равны
bne rs, rt, меткаперейти, если не равны
j меткабезусловный переход
jal меткаперейти и запомнить адрес возврата (вызов функции)
jr $raперейти по адресу из регистра (возврат из функции)

Метка — это имя места в программе; она заканчивается двоеточием.

if / else

Обрати внимание: в ассемблере проверяется обратное условие (bne — «если не равны, перепрыгни к else»).

Цикл while

Цикл for

У любого цикла один и тот же скелет: метка → проверка условия выхода (beq … done) → тело цикла → j обратно к метке.

Массивы

Массив — это соседние ячейки памяти. Базовый адрес — адрес элемента array[0]. Каждый элемент (слово) занимает 4 байта, поэтому array[1] лежит на 4 байта дальше, array[2] — на 8 байт дальше и т. д.

32-битный адрес не помещается в одну команду, поэтому его загружают в два шага: lui записывает старшие 16 бит, ori — младшие.

Функции и стек

Функции позволяют многократно использовать один и тот же код. Соглашение в MIPS:

  • аргументы передаются в регистрах $a0–$a3,
  • результат возвращается в регистре $v0,
  • jal переходит к функции и сохраняет адрес возврата в $ra; jr $ra возвращается.

Стек — область памяти для локальных переменных функции (и дополнительных аргументов). Работает по принципу LIFO — последний положенный элемент снимается первым. Указатель стека $sp показывает вершину; стек начинается с большого адреса и растёт вниз.

🧒По-простому

Стек — это стопка тарелок: кладёшь сверху и снимаешь сверху. Функция кладёт на него то, что должна сохранить, а перед возвратом снимает — в обратном порядке.

Остальные темы

  • Числа с плавающей точкой: в MIPS есть 32 отдельных регистра $f0–$f31 и поддержка стандарта IEEE (одинарная и двойная точность).
  • Режимы адресации — их пять:
РежимГде операндыПример

От исходного кода до работающей программы

🪜По шагам

  1. Компиляция — компилятор переводит код высокого уровня в ассемблер.
  2. Ассемблирование — ассемблер превращает код в объектный файл с машинным языком; назначает адреса командам и меткам.
  3. Компоновка (linking) — компоновщик объединяет объектные файлы (в том числе из библиотек) в один исполняемый файл.
  4. Загрузка — операционная система считывает исполняемый файл с диска в память и запускает программу.

Почти все персональные компьютеры используют процессоры архитектуры x86 — пример CISC.

Регистры MIPS

$0 = ноль · $t0–$t7 временные (8–15) · $s0–$s7 переменные (16–23) · $a0–$a3 аргументы · $v0 результат · $sp стек · $ra адрес возврата

Команды

КомандаЗначение
add rd, rs, rt / subrd = rs ± rt
addi rt, rs, immrt = rs + константа

Форматы (32 бита)

Поля
Rop(6)=0 · rs(5) · rt(5) · rd(5) · shamt(5) · funct(6)
Iop(6) · rs(5) · rt(5) · imm(16)
Jop(6) · addr(26)
  • funct: add = 32, sub = 34, and = 36, or = 37, slt = 42. op: addi = 8, lw = 35, sw = 43, beq = 4.
  • Декодирование: hex → двоичный вид → первые 6 бит (opcode) → разбивка на поля.

Память

  • Байтовая адресация; слово = 4 байта → адреса слов: 0, 4, 8… array[i] = база + 4·i.
  • Стек: LIFO, $sp, растёт вниз. Функция: аргументы $a0–$a3, результат $v0, jal / jr $ra.
  • Компилятор → ассемблер → компоновщик → загрузчик.
  • MIPS = RISC (простые, 3 операнда, 4 байта); x86 = CISC (2 операнда, переменная длина).
