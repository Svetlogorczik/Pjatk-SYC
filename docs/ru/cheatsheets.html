Правила

  • Масса (GND) = условные 0 В, обычно минус питания.
  • Условно ток течёт от «+» к «−».
  • Предел: наименьший, в который результат помещается; измеряй ближе к концу предела.
  • Разрешение Δr = цена последней цифры на дисплее (зависит от предела!).
  • Погрешность → максимум 2 значащие цифры; результат → тот же знак после запятой; запись x ± Δx.
  • График: крестики + гладкая линия, никогда не ломаная.

  • Нижних частот: R последовательно, C на массу — пропускает низкие f.

  • Линейная система: синус на входе → синус той же частоты на выходе.

Лекция 4. Полупроводники: диоды и транзисторы

Полупроводники

n-типp-тип
Примесьдонор, V группа (P, As)акцептор, III группа (B, Al)
Основные носителиэлектроныдырки
  • p-n-переход: диффузия → рекомбинация → обеднённая область → потенциальный барьер.
  • Прямое включение: «+» на p (анод), «−» на n (катод). Обратное: наоборот — ток не течёт.

Диод

  • Проводит от анода к катоду, когда напряжение превысит порог: кремниевый ≈ 0,6 В; красный светодиод ≈ 2 В ✚.
  • Светодиод: длинная ножка = анод (+). Всегда с резистором: R = Uпит − ULEDI ✚.

Биполярный транзистор

  • Выводы: E (эмиттер), B (база), C (коллектор). Стрелка = эмиттер. NPN: стрелка наружу, PNP: внутрь.
  • Маленький ток базы управляет большим током коллектора: IC = β · IB, β > 100.
  • Включается при UBE ≈ 0,6 В (переход Б–Э в прямом направлении).
  • Характеристики: входная IB(UBE), выходная IC(UCE), передаточная IC(IB) — линейная.
  • Как ключ ✚: нет тока базы → закрыт (выключен); большой ток базы → насыщен (включён).

Полевые транзисторы

  • Выводы: S (исток), D (сток), G (затвор). Управляются напряжением затвора, ток затвора ≈ 0.
  • JFET: затвор сужает канал. gm = dIDSdVGS.
  • MOSFET: затвор изолирован оксидом; основа цифровых схем (CMOS).

Лекция 5. Операционные усилители

Операционный усилитель

  • Усиливает разность: Vout = k · (V+ − V−), k огромное (10⁵…10⁷).
  • Идеал: k = ∞, Zin = ∞, Zout = 0, входной ток 0, смещение 0.
  • Выход не выйдет за пределы питания (насыщение). Полоса × усиление = const.
  • ✚ При отрицательной обратной связи: во входы ток не течёт и V+ = V−.

  • R₂ — это всегда резистор в обратной связи (между выходом и входом «−»).

Лекция 6. Цифровые схемы — введение: сигналы, вентили, булева алгебра

Логические уровни

  • TTL (5 В, биполярные транзисторы): 0 → 0–0,8 В; 1 → 2–5 В; между ними — неопределённость.
  • CMOS (3–18 В, пары МОП): 0 → 0–30% питания; 1 → 70–100%; мощность только при переключении.
  • Hi-Z — третье состояние (ничего не подключено); задаётся подтягивающим резистором (pull-up).

Вентили

Булева алгебра

  • a + a = 1, a · a = 0, a + ab = a, a(a+b) = a
  • a(b+c) = ab + ac, a + bc = (a+b)(a+c)
  • Де Морган: a + b = a · b, a · b = a + b
  • Склеивание: ab + ab = a

Канонические формы

  • Суммарная (ДНФ), Σ: по строкам с 1; произведение переменных, 0 → отрицание; произведения соединяем «+».
  • Мультипликативная (КНФ), Π: по строкам с 0; сумма переменных, 1 → отрицание; суммы соединяем «·».
  • Номер строки = десятичное значение входных битов.

Только из NAND

NOT a = a·a; a AND b = a·b; a OR b = a·b

Только из NOR

NOT a = a+a; a OR b = a+b; a AND b = a+b

Лекция 7. Минимизация булевых функций: карты Карно

Карта Карно — порядок действий

  1. Нарисуй карту; столбцы и строки в коде Грея: 00, 01, 11, 10.
  2. Впиши значения из таблицы истинности (следи за порядком столбцов!).
  3. Отметь группы: прямоугольники по 1, 2, 4, 8 клеток; как можно больше по размеру, как можно меньше по числу; могут пересекаться; края и углы соприкасаются ✚.
  4. Для каждой группы: выбрось переменные, которые меняются, запиши постоянные.

На NAND / NOR

  • NAND: суммарная форма → двойное отрицание → де Морган: ab + cd = ab · cd
  • NOR: мультипликативная форма → двойное отрицание → де Морган: (a+b)(c+d) = a+b + c+d
  • Склеивание: a·f + a·f = f. Код Грея (3 бита): 000, 001, 011, 010, 110, 111, 101, 100.

Лекция 8. Комбинационные функциональные блоки: мультиплексор, дополнительный код, сумматор, АЛУ

Мультиплексор

  • n адресных входов → 2n информационных; выход = вход с номером, поданным на адрес.
  • Функция на MUX 16:1: на входы с номерами из списка Σ подай 1, на остальные 0.
  • Функция на MUX 8:1: 3 переменные на адрес, четвёртая «свободная» x. Для каждого адреса сравни y при x = 0 и x = 1:
y(x=0), y(x=1)0, 01, 10, 11, 0
на вход01xx
  • Свободная x3: пары строк (k, k+8). Свободная x0: пары (2k, 2k+1).
  • DMUX: один вход → выход, указанный адресом. Дешифратор: NKB → 1 из N.

Дополнительный код U2 (N бит)

  • Вес старшего бита: −2N−1. Диапазон: −2N−1 … 2N−1−1 (4 бита: −8…7; 8 бит: −128…127).
  • Противоположное число: инвертируй биты, прибавь 1.
  • Сложение как в NKB; перенос из старшего бита игнорируй. Вычитание: a + (−b).
  • Переполнение = CIN ⊕ COUT старшего бита (положительное + положительное = отрицательное или наоборот).
4 бита U20111000100001111111010011000

Сумматор и АЛУ

  • Полный сумматор: y = a ⊕ b ⊕ c0, c = ab + ac0 + bc0. n-разрядный сумматор = каскад.
  • Полусумматор (без входного переноса) ✚: s = a ⊕ b, c = ab.
  • АЛУ: A, B — данные; F — код операции; R — результат; D — флаги. Все операции считаются сразу, MUX выбирает результат.
  • Другие коды: BCD (цифра → 4 бита), ZM (бит знака + модуль), U1 (инверсия битов), Грея, 1 из N.

Счётчики

Лекция 10. Проектирование синхронных последовательностных схем

Процедура (автомат Мура, D-триггеры)

  1. Состояния и выходы — выпиши, что должно быть на выходах в каждом состоянии.
  2. Граф / таблица переходов — для каждого состояния и каждой комбинации входов: следующее состояние.
  3. Кодирование — n триггеров, 2n ≥ числа состояний; коды лучше в порядке Грея (00, 01, 11, 10).
  4. Закодированная таблица — вместо названий состояний впиши коды.
  5. Функции возбуждения — для D-триггера: Di = i-й бит следующего состояния. Карта Карно по переменным: биты состояния + входы.
  6. Функции выходов — карта Карно только по переменным состояния (Мур).
  7. Схема — триггеры на общем тактовом сигнале + вентили.

Запомнить

  • Мур: выход = f(состояние) — значения в кружках. Мили: выход = f(состояние, вход) — значения у стрелок.
  • Из каждого состояния должна выходить стрелка для каждой комбинации входов.
  • Кодирование — коды, отличающиеся 1 битом, для: (1) состояний с одним и тем же следующим состоянием, (2) следующих состояний одного состояния, (3) состояний с одинаковыми выходами.
  • Эквивалентные состояния: те же выходы + следующие состояния одинаковы или эквивалентны → объединяем в одно.
  • Неопределённые клетки (лишние коды, невозможные входы) — вписывай что удобно.
  • Полезно: XOR = ab + ab; формулы часто упрощаются до XOR/AND/NOT.

Лекция 11. Компьютерные системы, микропроцессоры и микроконтроллеры

Компьютер

  • Фон Нейман: процессор (с АЛУ) + память (данные и программа вместе) + ввод/вывод; команды выполняются по очереди.
  • Гарвард: отдельная память программы и данных (микроконтроллеры: Flash + RAM).
  • Командный цикл: выборка → декодирование → выполнение.
  • Регистры: PC (адрес следующей команды), регистр команд, аккумулятор, SP (стек), регистр флагов.
  • Шины: адреса, данных, управления.
  • CISC: много сложных команд, разное время. RISC: мало простых команд, один цикл, конвейер.

Микроконтроллер

µC = процессор + RAM + память программы + порты ввода-вывода + периферия (UART, SPI, I²C, АЦП, таймеры, watchdog) в одной микросхеме.

Лекция 12. Способы связи: порты, UART, SPI, I²C

Понятия

  • Последовательная (бит за битом) / параллельная (байт сразу).
  • Синхронная (общий тактовый сигнал) / асинхронная (START + STOP, договорённая скорость).
  • Симплекс (в одну сторону) / полудуплекс (по очереди) / полный дуплекс (одновременно).

Лекция 13. Периферия микроконтроллеров и обработка событий

Выводы и ШИМ

  • pinMode(pin, OUTPUT / INPUT / INPUT_PULLUP); максимум 40 мА на вывод; выход нельзя замыкать на массу или питание.
  • ШИМ: заполнение ω = τT; среднее напряжение = заполнение × 5 В. Arduino: analogWrite(pin, 0…255), около 490 Гц.
  • Серво: импульс каждые 20 мс (50 Гц); 1,5 мс = нейтральное положение (90°).
  • АЦП: 10 бит → 0…1023; U = показание · 51023 ✚. «Аналоговый» выход = ШИМ + фильтр.

Транзистор как ключ

  • Отсечка (нет тока базы) = выключен; насыщение (большой ток базы) = включён.
  • H-мост: S1+S4 → одно направление, S2+S3 → противоположное; скорость — ШИМ.

Преобразователи

  • ЦАП с взвешенными резисторами: операционный усилитель как сумматор токов.
  • АЦП flash: 2n − 1 компараторов, очень быстрый, мало бит.
  • АЦП последовательных приближений: n сравнений для n бит (сначала с половиной диапазона).

  • Прерывания: аппаратные (внешние, от таймера, исключения) и программные; маскируемые / немаскируемые (сброс).
  • Вектор прерывания = адрес обработчика; PC кладётся в стек.
  • Обработка: определи → сбрось причину → запрети → регистры в стек → обработай → регистры из стека → разреши → вернись.
  • AVR: приоритетов нет (плоская система).
  • Arduino: attachInterrupt(digitalPinToInterrupt(2), функция, CHANGE | RISING | FALLING); общие переменные: volatile.

Лекция 14. Архитектура компьютеров: процессор MIPS изнутри

Понятия

  • Архитектура = набор команд + состояние (регистры, память). Микроархитектура = способ аппаратной реализации.

Лабораторная 1. Вводное занятие: оборудование лаборатории

Мультиметр

  • Чёрный провод всегда в COM. Красный: VΩ (напряжение, сопротивление) или mA / 20A (ток).
  • Напряжение — параллельно. Ток — последовательно. Сопротивление — без питания.
  • «1» на дисплее = предел слишком мал. Неизвестное значение → начинай с наибольшего предела.

Лабораторная 5. Диоды и транзисторы: светодиод, проверка транзистора, транзисторный ключ

Светодиод

  • Длинная ножка = анод (+). Светится, когда анод со стороны плюса.

  • Проверка диодов: (+) на аноде → прямое напряжение; наоборот → «1» / «.0L».

J1: IN+ → (+) · J2: IN− → (−) · J3: (+) → масса · J4: (−) → масса · J5: (−) → выход

Формулы

  • Неинвертирующий: kU = 1 + R2R1 — выход в фазе
  • Инвертирующий: kU = R2R1 — выход перевёрнут (180°)
  • Измерение: Uвх = a · Sa, Uвых = b · Sb, kU = UвыхUвх
  • Смещение: U = деления · чувствительность (мВ/дел, вход на массе)
  • Компаратор: V+ > V− → +Vc; иначе −Vc. Положительное смещение → дольше высокий уровень.

Помни

  • R2 = больший резистор, всегда в J5. Резисторы измерь мультиметром до установки.
  • Генератор: синус 1 кГц, маленькая амплитуда (чтобы не было обрезания при ±12 В).
  • Проверь питание модуля и общую массу.

Лабораторная 7. Введение в цифровые схемы: Logisim, таблица истинности, вентили

Logisim

  • Вход = зелёный квадрат, выход = зелёный кружок, вентили в папке Gates.
  • Рука (Poke) меняет вход 0 ↔ 1; стрелка (Edit) рисует провода.
  • Цвета: ярко-зелёный = 1, тёмно-зелёный = 0, синий = не подключено, красный = конфликт.
  • Новая схема: Project → Add Circuit…; потом ставишь её как вентиль.
  • Таблица истинности схемы: Project → Analyze Circuit. ✚

Путь проектирования

  1. Словесное описание → таблица истинности (строки в двоичном порядке: 000, 001, …).
  2. Таблица → формула: для каждой единицы произведение переменных (0 → с отрицанием), всё сложить.
  3. Формула → схема: сначала NOT, потом AND, в конце OR.
  4. Тест всех комбинаций.
