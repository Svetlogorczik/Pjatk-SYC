Пример из материалов: робот, объезжающий препятствия

Стартовый файл лежит на сервере с материалами: mmajew/SYC/07 and 08/07 and 08 lab mobile robot.circ.

Словесное описание. У робота три датчика препятствий: A слева, B спереди, C справа. Датчик даёт 1, когда видит препятствие. Привод — два мотора: левый LM и правый RM; мотор работает, когда получает 1. Робот должен ехать без столкновений, а когда ехать некуда — остановиться.

🧒По-простому

Робот поворачивает как танк: когда крутится только правый мотор, робот поворачивает налево. Только левый — направо. Оба — едет прямо. Ни один — стоит.

Шаг 2: формулы

Из таблицы (после упрощения картой Карно — это тема следующего занятия) получается:

LM = b·c + a·c + a·b  RM = a + b·c

Шаг 3: схема из вентилей NOT, AND, OR

🪜По шагам

  1. Поставь три входа и подпиши их a, b, c. Поставь выход и подпиши RM.
  2. Посчитай, что тебе нужно. Для RM = a + b·c: два NOT (для a и b), один AND (для b·c), один OR.
  3. Ставь вентили слева направо, в порядке формулы: сначала отрицания, потом произведение, в конце сумма.
  4. Соедини проводами. Ни один провод не должен остаться синим.
  5. Рукой выставь по очереди все 8 комбинаций и сравни RM с таблицей.
  6. То же самое для LM — в том же файле, рядом (входы a, b, c могут быть общими).

💡Хорошая привычка

Каждому вентилю дай подпись с тем, что он считает (на картинке: a*-c, -b*c). Когда результат не сходится, сразу видно, какой кусок формулы неправильный.

Вентили NOT, AND, OR из одних NAND

Вентиль NAND универсальный: из него можно построить любой другой. На занятии ты собираешь три «кирпичика» — каждый в отдельной схеме (Project → Add Circuit).

КирпичикКак собратьСколько NANDПочему работает
NOTоба входа NAND соединены вместе1a·a = a
ANDNAND, а за ним NOT2двойное отрицание: a·b = a·b
ORNOT на каждом входе, потом NAND3де Морган: a·b = a + b

🪜По шагам

  1. Project → Add Circuit…, имя, например, NOT_nand. Поставь вход, один вентиль NAND, выход. Оба входа NAND соедини с одним и тем же входом. Проверь: 0 → 1, 1 → 0.
  2. Новая схема AND_nand: два входа → NAND → второй NAND с соединёнными входами → выход. Проверь 4 комбинации.
  3. Новая схема OR_nand: каждый вход через «NOT из NAND», потом NAND. Проверь 4 комбинации.
  4. Вернись в схему main. Твои схемы теперь в списке слева — кликаешь по ним и ставишь как обычные вентили.
  5. Нарисуй функцию ещё раз, но вместо NOT/AND/OR поставь свои кирпичики — в том же расположении, что и формула.
  6. Проверь все комбинации: результат должен быть таким же, как в версии с обычными вентилями.

Схема из кирпичиков работает, но она большая (на картинке: 7 вентилей NAND для RM). Как её уменьшить — на следующем занятии.

📝2. От таблицы к формуле

Функция трёх переменных равна 1 только для abc = 001 и abc = 110. Запиши её формулу и посчитай вентили.

✅Показать решение

Для каждой единицы пишем произведение всех переменных — переменная с нулём получает отрицание:

y = a·b·c + a·b·c

Вентили: 3 NOT, 2 AND (трёхвходовых), 1 OR.

📝3. XOR из четырёх NAND

XOR, расписанный из кирпичиков, стоит 9 вентилей NAND. Это можно сделать четырьмя. Проверь таблицей истинности, что схема: n1 = a·b, n2 = a·n1, n3 = b·n1, y = n2·n3 — это XOR.

📝4. Сколько вентилей NAND?

Функция y = a·b + c. Сколько вентилей NAND нужно методом кирпичиков? А сколько после упрощения?

✅Показать решение

Кирпичики: AND (2) + OR (3) = 5 вентилей.

Упрощение: y = a·b + c = a·b·c — то есть NAND от двух сигналов: a·b (один NAND) и c (один NAND с соединёнными входами). Всего 3 вентиля.

📝5. Собери в Logisim

Нарисуй функцию из примера (y = a·b + (b ⊕ c)) на обычных вентилях, потом рядом — из кирпичиков NAND, используя для XOR версию из задания 3. Сколько вентилей NAND получилось?

✅Показать решение

NOT (1) + AND (2) + XOR (4) + OR (3) = 10 вентилей вместо 15. Обе схемы должны дать столбец y: 0, 1, 1, 1, 0, 1, 1, 0.

💡На чём чаще всего теряют баллы

  • Синий провод — неподключённый вход вентиля. У вентиля в Logisim по умолчанию 5 входов; неиспользуемые игнорируются, но лучше выставить Number Of Inputs ровно столько, сколько нужно.
  • Провод, который выглядит подключённым, а на самом деле нет (нет точки на пересечении).
  • Проверка только 2–3 комбинаций вместо всех.
  • Неправильный порядок строк в таблице истинности — всегда считай в двоичной системе: 000, 001, 010, 011…
  • Кирпичик NAND, проверенный «на глаз», но с ошибкой — каждый кирпичик протестируй отдельно, прежде чем использовать.

📋 Краткий конспект (шпаргалка)

Самое важное по теме — чтобы быстро повторить перед занятием.

Logisim

  • Вход = зелёный квадрат, выход = зелёный кружок, вентили в папке Gates.
  • Рука (Poke) меняет вход 0 ↔ 1; стрелка (Edit) рисует провода.
  • Цвета: ярко-зелёный = 1, тёмно-зелёный = 0, синий = не подключено, красный = конфликт.
  • Новая схема: Project → Add Circuit…; потом ставишь её как вентиль.
  • Таблица истинности схемы: Project → Analyze Circuit. ✚

Путь проектирования

  1. Словесное описание → таблица истинности (строки в двоичном порядке: 000, 001, …).
  2. Таблица → формула: для каждой единицы произведение переменных (0 → с отрицанием), всё сложить.
  3. Формула → схема: сначала NOT, потом AND, в конце OR.
  4. Тест всех комбинаций.
