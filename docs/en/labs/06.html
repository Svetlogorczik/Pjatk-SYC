Lab 6

The operational amplifier: follower, comparator, non-inverting and inverting amplifier

On one board, by moving five jumpers, you build four circuits. For the amplifiers you first calculate the gain from the resistors and then check on the oscilloscope whether reality agrees.

📋 Quick summary Lecture for this lab: Lecture 5 →

✚ = added by the site author — not in the slides or the lecture recording

What you need to know before the class

  • The gain formulas of the inverting and non-inverting amplifier, how the follower and the comparator work — lecture 5 (Quick summary).
  • Measuring amplitudes on two oscilloscope channels — lab 4.

🎓From lecture 1 (2026/27)

"You will have to design and calculate an inverting and a non-inverting amplifier. Then those amplifiers have to be assembled to see how the calculations compare with the physically built amplifiers." And a warning: a common gross error is measuring an amplifier that was never powered.

The lab module

The board holds one operational amplifier (an LM358) powered from ±12 V. Which circuit you get is decided by five jumpers:

JumperWhat it connects
J1the IN+ socket to the non-inverting (+) input of the op-amp
J2the IN− socket to the inverting (−) input
J3the (+) input to ground
J4the (−) input to ground
J5the (−) input to the output (the feedback loop)

Each jumper can be open (no connection), closed (shorted) or replaced by a resistor plugged between its pins via the breadboard.

⚠️Watch out

The board's ground is wired to the ground (GND) of the breadboard — the grounds of the generator and the oscilloscope must go there. Before every measurement check that the module is powered.

Task 1 — offset voltage (the follower)

A follower should output exactly what is at its input. We short the input to ground — the output should be 0 V. What remains there is the offset voltage.

J1J2J3J4J5
openopenclosedopenclosed

🪜Step by step

  1. Set the jumpers as in the table: J3 shorts the (+) input to ground, J5 connects the output to the (−) input.
  2. Connect oscilloscope channel CH2 to the OUT output, ground to GND.
  3. Oscilloscope input switch to GND — centre the zero line; then switch to DC.
  4. Set the highest sensitivity (e.g. 5 mV/div) — the voltage is very small.
  5. Read by how many divisions the line moved away from zero and multiply by the sensitivity.

🔎Example from the lab materials

Uoffset = 1.4 div · 5 mV/div = 7.0 mV

Task 2 — the comparator

Without feedback the op-amp compares the voltages at its inputs: when "+" has more than "−", the output jumps to the positive supply voltage, otherwise to the negative one.

J1J2J3J4J5
closedopenopenclosedopen

🪜Step by step

  1. Set the jumpers: J1 passes the signal from IN+ to the (+) input, J4 shorts the (−) input to ground, J5 open — no feedback.
  2. Generator: 1 kHz sine, small amplitude. Connect it to IN+ and at the same time to oscilloscope CH1.
  3. Oscilloscope CH2 — to the OUT output; sensitivity about 5 V/div, input in DC mode.
  4. MODE → DUAL. Sketch both waveforms one under the other.
  5. Use the generator's OFFS knob to add a positive DC component — sketch what changed.
  6. Turn OFFS the other way (negative DC component) — sketch again.

What you will see: the output is a square wave of the same frequency. While the sine is above zero the output is positive (+Vc, about 12 V); while below — negative.

  • A positive DC component lifts the sine — more of it is above zero, so the square wave is high for longer.
  • A negative one — the opposite: the high state is shorter.

✚From the site author (not in the lecture)

A comparator with a 0 V threshold is really the simplest "analog → digital" converter: it only answers "more" or "less". The fast A/D converter from lecture 13 is built from such comparators.

Task 3 — the non-inverting amplifier

J1J2J3J4J5
closedopenopenR1R2

🪜Step by step

  1. Measure both resistors with the multimeter (out of the circuit). The larger one is R2, the smaller one R1. Write the values down.
  2. Calculate the gain: kU = 1 + R2R1.
  3. Build the circuit: R1 between the pins of jumper J4 ("−" input to ground), R2 between the pins of J5 ("−" input to the output), J1 closed.
  4. Generator (1 kHz sine) — to IN+ and to CH1. CH2 — to OUT.
  5. Choose the sensitivities and write down: a — input divisions, Sa — CH1 sensitivity, b — output divisions, Sb — CH2 sensitivity.
  6. Compute Uin = a · Sa, Uout = b · Sb and the measured gain kU = UoutUin.
  7. Sketch both waveforms. Compare the calculated gain with the measured one.

🔎Example from the lab materials

a = 4 div, Sa = 0.5 V/div → Uin = 2 V; b = 8 div, Sb = 0.5 V/div → Uout = 4 V

kU = 42 = 2 — so in this example R1 = R2 (because 1 + 1 = 2). The output is in phase with the input.

Task 4 — the inverting amplifier

The same resistors, a different connection: the signal enters through R1 to the "−" input, and the "+" input is grounded.

J1J2J3J4J5
openR1closedopenR2

🪜Step by step

  1. Calculate the gain: kU = R2R1 (the form has no minus — the minus only means a phase inversion).
  2. Rebuild the circuit: R1 between the pins of J2 (from IN− to the "−" input), R2 stays in J5, J3 closed ("+" input to ground), J1 and J4 open.
  3. Generator (1 kHz sine) — now to IN− and to CH1. CH2 — to OUT.
  4. Measure a, Sa, b, Sb, compute kU and sketch the waveforms.

🔎Example from the lab materials

a = 8 div, b = 8 div, both sensitivities 0.5 V/div → kU = 44 = 1 (the same resistors, R1 = R2). The output is inverted: where the input has a peak, the output has a trough.

Jumper summary

CircuitJ1J2J3J4J5Signal
Follower (offset)——closed—closednone (input grounded)
Comparatorclosed——closed—IN+
Non-invertingclosed——R1R2IN+
Inverting—R1closed—R2IN−

💡How to remember it

R2 is always in J5 (feedback: from the output to the "−" input). R1 always touches the "−" input: in the non-inverting circuit it goes to ground (J4), in the inverting one to the signal (J2). The input that gets no signal is shorted to ground.

Practice tasks

📝1. Gain from the resistors

Measured: R1 = 4.7 kΩ and R2 = 15 kΩ. Calculate the gain of the non-inverting and of the inverting circuit.

✅Show solution

Non-inverting: kU = 1 + 154.7 = 4.19

Inverting: kU = 154.7 = 3.19 (with phase inversion, i.e. −3.19)

📝2. Gain from the oscilloscope

For the non-inverting circuit of task 1 you read: a = 3 divisions at Sa = 0.2 V/div; b = 5.1 divisions at Sb = 0.5 V/div. What is the measured gain and by what percentage does it differ from the calculated one?

✅Show solution

Uin = 3 · 0.2 = 0.6 V; Uout = 5.1 · 0.5 = 2.55 V; kU = 2.550.6 = 4.25

Difference: 4.25 − 4.194.19 ≈ 1.4% — very good agreement (the resistors and the screen reading have their own errors).

📝3. A clipped signal

A non-inverting amplifier: R1 = 1 kΩ, R2 = 10 kΩ, supply ±12 V. The input is a sine of 3 V peak-to-peak. What will you see at the output?

✅Show solution

kU = 1 + 10 = 11 → the output "should" be 3 · 11 = 33 V peak-to-peak, i.e. ±16.5 V. The supply is only ±12 V, so the amplifier saturates: the peaks of the sine are clipped flat around ±12 V (a little less in practice).

To measure the gain you have to reduce the generator amplitude until the output sine is clean.

📝4. A comparator with a DC component

The "+" input of a comparator gets a sine of amplitude 1 V with a DC component of +0.5 V; the "−" input is grounded. For what fraction of the period is the output high?

✅Show solution

The output is high when sin(x) + 0.5 > 0, i.e. sin(x) > −0.5. The sine is below −0.5 only between 210° and 330° — 120° out of 360°.

So the high state lasts 240°360° = 23 of the period (about 67%).

📝5. Design an amplifier

You need a non-inverting amplifier with a gain of 6. You have R1 = 2 kΩ. What should R2 be? What gain does the same pair give in the inverting circuit?

✅Show solution

1 + R22 = 6 → R2 = 10 kΩ. In the inverting circuit: 102 = 5 (with phase inversion).

💡What costs points most often

  • A module without power (the classic gross error) or no common ground.
  • R1 and R2 swapped — the gain then comes out smaller than calculated.
  • Too large an amplitude from the generator → a clipped sine → an underestimated "gain".
  • A jumper left over from the previous task (e.g. J3 closed in the non-inverting circuit shorts the signal to ground).
  • Measuring the offset at too low a sensitivity (the line "sits on zero") — switch to mV/div.

📋 Quick summary (cheat sheet)

The essentials of this topic — for a fast recap before the lab.

Jumpers

CircuitJ1J2J3J4J5Signal on
Follower (offset)——closed—closed—
Comparatorclosed——closed—IN+
Non-invertingclosed——R1R2IN+
Inverting—R1closed—R2IN−

J1: IN+ → (+) · J2: IN− → (−) · J3: (+) → ground · J4: (−) → ground · J5: (−) → output

Formulas

  • Non-inverting: kU = 1 + R2R1 — output in phase
  • Inverting: kU = R2R1 — output inverted (180°)
  • Measurement: Uin = a · Sa, Uout = b · Sb, kU = UoutUin
  • Offset: U = divisions · sensitivity (mV/div, input grounded)
  • Comparator: V+ > V− → +Vc; otherwise −Vc. Positive offset → high for longer.

Remember

  • R2 = the larger resistor, always in J5. Measure the resistors with the multimeter before plugging them in.
  • Generator: 1 kHz sine, small amplitude (to avoid clipping at ±12 V).
  • Check the module's power and the common ground.
