Introduction to digital circuits: Logisim, truth table, gates

From this class on there are no more cables or oscilloscopes — you draw circuits in Logisim and see at once whether they work. You learn the path: verbal description → truth table → formula → gate schematic, and finally you build everything from NAND gates only.

💡Checking a circuit

Clicking with the hand, go through all input combinations (8 of them for 3 inputs) and compare the output with the truth table. Faster: menu Project → Analyze Circuit — Logisim prints the truth table of the drawn circuit itself. ✚

Example from the materials: an obstacle-avoiding robot

The starter file is on the materials server: mmajew/SYC/07 and 08/07 and 08 lab mobile robot.circ.

Verbal description. The robot has three obstacle sensors: A on the left, B in front, C on the right. A sensor gives 1 when it sees an obstacle. The drive is two motors: left LM and right RM; a motor runs when it gets 1. The robot should drive without collisions and stop when there is nowhere to go.

🧒In plain words

The robot turns like a tank: when only the right motor runs, the robot turns left. Only the left one — right. Both — straight ahead. Neither — it stands still.

For each of the 8 situations we decide what the motors should do.

Step 2: the formulas

From the table (after simplifying with a Karnaugh map — the topic of the next class) we get:

LM = b·c + a·c + a·b  RM = a + b·c

Step 3: a schematic from NOT, AND, OR gates

🪜Step by step

  1. Insert three inputs and label them a, b, c. Insert an output and label it RM.
  2. Count what you need. For RM = a + b·c: two NOTs (for a and b), one AND (for b·c), one OR.
  3. Place the gates from left to right, in the order of the formula: negations first, then the product, the sum last.
  4. Connect them with wires. No wire may stay blue.
  5. With the hand set all 8 combinations one by one and compare RM with the table.
  6. The same for LM — in the same file, next to it (inputs a, b, c can be shared).

💡A good habit

Give each gate a label saying what it computes (in the picture: a*-c, -b*c). When the result is wrong, you see at once which piece of the formula is bad.

NOT, AND, OR gates from NAND only

The NAND gate is universal: any other gate can be built from it. In class you build three "bricks" — each in a separate circuit (Project → Add Circuit).

BrickHow to build itNANDsWhy it works
NOTboth NAND inputs tied together1a·a = a
ANDa NAND followed by a NOT2double negation: a·b = a·b
ORa NOT on each input, then a NAND3De Morgan: a·b = a + b

🪜Step by step

  1. Project → Add Circuit…, name e.g. NOT_nand. Insert an input, one NAND gate, an output. Connect both NAND inputs to the same input. Check: 0 → 1, 1 → 0.
  2. A new circuit AND_nand: two inputs → NAND → a second NAND with tied inputs → output. Check the 4 combinations.
  3. A new circuit OR_nand: each input through a "NOT from NAND", then a NAND. Check the 4 combinations.
  4. Go back to the main circuit. Your circuits are now in the list on the left — you click them and place them like ordinary gates.
  5. Draw the function once more, but instead of NOT/AND/OR insert your bricks — in the same arrangement as the formula.
  6. Check all combinations: the result must be identical to the version with ordinary gates.

The circuit made of bricks works but is large (in the picture: 7 NAND gates for RM). How to shrink it — in the next class.

A bathroom fan should switch on (F = 1) when it is too warm (T = 1) or when it is humid (H = 1) and the window is closed (W = 0). Write the formula and the truth table.

Gates: 1 NOT, 1 AND, 1 OR.

📝2. From a table to a formula

A function of three variables equals 1 only for abc = 001 and abc = 110. Write its formula and count the gates.

✅Show solution

For each one we write the product of all variables — a variable that is zero gets a negation:

y = a·b·c + a·b·c

Gates: 3 NOT, 2 AND (three-input), 1 OR.

📝3. XOR from four NANDs

An XOR expanded from bricks costs 9 NAND gates. It can be done with four. Check with a truth table that the circuit: n1 = a·b, n2 = a·n1, n3 = b·n1, y = n2·n3 is an XOR.

✅Show solution
abn1n2n3y
001110
011101

The y column is exactly XOR. Conclusion: building "brick by brick" always works but is rarely the shortest.

📝4. How many NAND gates?

The function y = a·b + c. How many NAND gates does the brick method need? And how many after simplification?

✅Show solution

Bricks: AND (2) + OR (3) = 5 gates.

Simplification: y = a·b + c = a·b·c — a NAND of two signals: a·b (one NAND) and c (one NAND with tied inputs). 3 gates in total.

📝5. Build it in Logisim

Draw the function from the example (y = a·b + (b ⊕ c)) with ordinary gates, then next to it — from NAND bricks, using the XOR version from task 3. How many NAND gates did you get?

✅Show solution

NOT (1) + AND (2) + XOR (4) + OR (3) = 10 gates instead of 15. Both circuits must give the y column: 0, 1, 1, 1, 0, 1, 1, 0.

💡What costs points most often

  • A blue wire — an unconnected gate input. A gate in Logisim has 5 inputs by default; unused ones are ignored, but it is better to set Number Of Inputs to exactly what you need.
  • A wire that looks connected but is not (no dot at the crossing).
  • Checking only 2–3 combinations instead of all of them.
  • Wrong row order in the truth table — always count in binary: 000, 001, 010, 011…
  • A NAND brick checked "by eye" but faulty — test every brick separately before using it.

📋 Quick summary (cheat sheet)

The essentials of this topic — for a fast recap before the lab.

Logisim

  • Input = green square, output = green circle, gates in the Gates folder.
  • The hand (Poke) toggles an input 0 ↔ 1; the arrow (Edit) draws wires.
  • Colours: bright green = 1, dark green = 0, blue = not connected, red = conflict.
  • A new circuit: Project → Add Circuit…; then you place it like a gate.
  • Truth table of a circuit: Project → Analyze Circuit. ✚

The design path

  1. Verbal description → truth table (rows in binary: 000, 001, …).
  2. Table → formula: for each one a product of the variables (0 → negated), sum everything.
  3. Formula → schematic: NOT first, then AND, OR last.
  4. Test all combinations.
