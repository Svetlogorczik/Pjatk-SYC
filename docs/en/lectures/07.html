Lecture 7

Minimisation of Boolean functions: Karnaugh maps

The same function may need ten gates or three. A Karnaugh map is a way to find the shorter version without guessing — and then build it from NAND or NOR gates only.

The sum form (one product for every one — see lecture 6):

y = abc + abc + abc

Implemented "as is" it needs three inverters, three 3-input AND gates and an OR gate. Can it be done with fewer?

Transforming the formula

Using the laws of Boolean algebra a formula can be simplified:

abc + abc + abc = abc + ab(c + c) = abc + ab

(because c + c = 1). The lecture also shows a further transformation into (ab + ab)(a + b + c). All these formulas describe the same function — they are equivalent, so their circuits are equivalent too.

Why minimise? To make the circuit cheaper. You can aim for:

  • a smaller number of gates,
  • a smaller number of gate inputs,
  • less variety of gates (e.g. NAND only),
  • a shorter design time.

Transforming "by hand" is tedious and it is easy to miss something. Hence Karnaugh maps.

Gray code

000 → 001 → 011 → 010 → 110 → 111 → 101 → 100

In Gray code two consecutive words differ in only one bit. That also holds for the last and the first one (the code is cyclic). For two bits: 00, 01, 11, 10 — know this by heart.

The combining rule

a · f + a · f = (a + a) · f = f

If two products differ in only one variable (negated in one, plain in the other), they can be replaced by a single one — without that variable. Example: abc + abc = ab.

This is where Gray code comes in: if the rows of the table are put in Gray order, the products that can be combined lie next to each other.

The Karnaugh map

A Karnaugh map is a truth table drawn as a rectangle whose rows and columns are labelled in Gray-code order. Each cell is one row of the truth table.

Our function on the map (a in rows, bc in columns):

a \ bc00011110
00010
11100

⚠️Watch out

The columns go 00, 01, 11, 10, not 00, 01, 10, 11. The most common mistake in the lab is writing the values from rows 2 and 3 of the truth table into the wrong columns.

Grouping ones → the sum form

The rules from the lecture:

  1. Group ones that are adjacent horizontally or vertically, in a number that is a power of two (1, 2, 4, 8…).
  2. Each group gives one product. Drop the variable that changes within the group; keep those that stay constant.
  3. A constant variable equal to 1 enters plain, equal to 0 — negated.

For our map:

  • a group of two ones in the row a = 1, columns 00 and 01: c changes, a = 1 and b = 0 are constant → ab,
  • a lonely one in the cell a = 0, bc = 11 → abc.
y = ab + abc

Grouping zeros → the product form

The same, but we group zeros, and each group gives a sum. Drop the variable that changes and negate the rest (a variable equal to 0 enters plain, equal to 1 — negated).

  • zeros in the row a = 0, columns 00 and 01: constant a = 0, b = 0 → (a + b),
  • zeros in column 10 (both rows): constant b = 1, c = 0 → (b + c),
  • zeros in the row a = 1, columns 11 and 10: constant a = 1, b = 1 → (a + b).
y = (a + b) · (b + c) · (a + b)

Both forms are equivalent — multiplying out the brackets and simplifying gives ab + abc.

✚Grouping rules that are easy to forget

The slide gives only the rule "vertically or horizontally, in a number that is a power of two". In practice (and in the lab with a 4-variable function) you also need:

  • A group must be a rectangle: 1×2, 2×2, 1×4, 2×4… (no "L" shapes, no diagonals).
  • The edges of the map touch: the left column is adjacent to the right one, the top row to the bottom one. The four corners can also form one group.
  • Groups should be as large as possible (a larger group = a shorter product) and there should be as few as possible.
  • Groups may overlap — a one can be used many times.
  • Every one must belong to at least one group.
  • A group of 2 cells removes 1 variable, of 4 cells — 2 variables, of 8 cells — 3 variables.

y = Σ(0, 1, 2, 5, 8, 9, 10), variables a, b, c, d (row = ab, column = cd):

Cell numbers: row 00 → 0, 1, 3, 2; row 01 → 4, 5, 7, 6; row 11 → 12, 13, 15, 14; row 10 → 8, 9, 11, 10.

Groups:

  1. cells 0, 1, 8, 9 — rows 00 and 10 (top and bottom touch), columns 00 and 01. Constant: b = 0, c = 0 → bc
  2. cells 0, 2, 8, 10 — the four corners. Constant: b = 0, d = 0 → bd
  3. cells 1 and 5 — column 01, rows 00 and 01. Constant: a = 0, c = 0, d = 1 → acd
y = bc + bd + acd

Instead of 7 products of 4 variables each — three short ones.

Implementation with NAND gates only

Take the sum form, negate it twice (nothing changes) and break the "inner" negation with De Morgan's law:

y = ab + abc = ab + abc = ab · abc

Each product with a bar is a NAND gate, and the bar over the whole thing is one more NAND. In practice: an "ANDs, then OR" circuit becomes "NANDs, then NAND" with the same structure. Negations of single variables are also made with a NAND with its inputs tied together.

Implementation with NOR gates only

Take the product form and do the same:

y = (a+b)(b+c)(a+b) = (a+b) + (b+c) + (a+b)

An "ORs, then AND" circuit becomes "NORs, then NOR".

💡A short reminder

Want NAND → group the ones (sum form). Want NOR → group the zeros (product form). Then double negation and De Morgan.

Karnaugh map — the procedure

  1. Draw the map; columns and rows in Gray code: 00, 01, 11, 10.
  2. Fill in the values from the truth table (mind the column order!).
  3. Mark the groups: rectangles of 1, 2, 4, 8 cells; as large as possible, as few as possible; they may overlap; edges and corners touch ✚.
  4. For each group: drop the variables that change, write down the constant ones.

With NAND / NOR

  • NAND: sum form → double negation → De Morgan: ab + cd = ab · cd
  • NOR: product form → double negation → De Morgan: (a+b)(c+d) = a+b + c+d
  • Combining: a·f + a·f = f. Gray code (3 bits): 000, 001, 011, 010, 110, 111, 101, 100.
