Lecture 6

Digital circuits — introduction: signals, gates, Boolean algebra

From voltage to zeros and ones. What a logic state is, which gates exist, how to write a logic function, and why NAND gates alone are enough to build anything.

📋 Quick summary Lab for this lecture: Lab 7 →

✚ = added by the site author — not in the slides or the lecture recording

Analog, discrete and digital signals

  • Analog — continuous in time; it can take any value.
  • Discrete — its value is known only at fixed time intervals (samples).
  • Digital (logic) — only two states matter: 0 and 1. Each state corresponds to a range of voltages.

🧒In plain words

Analog is a light dimmer — any brightness. Digital is an ordinary switch — on or off. That is why small disturbances do no harm: "almost 5 V" is still a one.

Logic levels: TTL and CMOS

TTL

TTL circuits are built from bipolar transistors and powered from 5 V.

Voltage (relative to ground)State
0 V – 0.8 Vlogic 0 (low)
0.8 V – 2 Vundefined — not allowed
2 V – 5 Vlogic 1 (high)

CMOS

CMOS circuits consist of pairs of MOS transistors of opposite type (n-channel and p-channel) connected so that in a steady state only one of them conducts.

  • Simple and cheap to make, they allow very dense packing.
  • Supply 3–18 V; newer low-voltage families: 3.3 V, 2.5 V and even 1.8 V.
  • They draw almost no power at rest — only when the state changes.
  • Logic levels are close to the supply rails: "0" is 0–30% of the supply voltage, "1" is 70–100%.

The third state: high impedance

Besides 0 and 1 there is the high-impedance state (Hi-Z): a point of the circuit is connected to nothing — it "floats". To give such a point a defined state, it is connected through a resistor to the supply (a pull-up resistor) or to ground. Some gates have outputs that can be in the Hi-Z state (e.g. open collector gates).

🧒In plain words

Hi-Z is a phone with the plug pulled out: it says neither "yes" nor "no" — it is simply not on the line. A pull-up resistor is an agreement: "if nobody says anything, we take the answer to be YES". We come back to this with buttons and the I²C bus (lecture 12).

Boolean algebra

We work with two values {0, 1} and three operations. Different books use different symbols:

⚠️Watch out

In Boolean algebra "+" is OR, not addition: 1 + 1 = 1.

🧒In plain words

De Morgan in plain words: "it is not true that (it rains or it is windy)" is the same as "it does not rain and it is not windy". A bar over the whole thing can be "broken" in half, but then the sign in the middle flips.

✚Handy bits that are not on the slide

a + 0 = a, a · 1 = a, a + 1 = 1, a · 0 = 0, a + a = a, a · a = a, a = a (a double negation disappears).

Boolean function and truth table

A Boolean function of n variables assigns one output value (0 or 1) to every combination of zeros and ones at the inputs: f: Bn → B. It is the mathematical model of a combinational circuit — one whose output depends only on what is at the inputs right now.

Every function can be written as a truth table. For n inputs the table has 2n rows. Example — the XOR function:

Row no.abf(a,b)
0000
1011
2101
3110

The row number is the decimal number formed by the input bits (01 = 1, 10 = 2…). This lets us state a function briefly:

  • the set of ones: f1 = {1, 2} — rows where the result is 1; written f = Σ(1, 2),
  • the set of zeros: f0 = {0, 3} — rows where the result is 0; written f = Π(0, 3).

Two canonical forms

Sum form (DNF) — "sum of products"

Look at the rows with a one. Each such row gives one product of all the variables: a variable equal to 0 in that row enters negated, equal to 1 — plain. The products are joined by a sum.

For XOR: row 01 → ab, row 10 → ab:

f(a,b) = ab + ab = Σ(1, 2)

Product form (CNF) — "product of sums"

Look at the rows with a zero. Each gives one sum, but here it is the other way round: a variable equal to 0 enters plain, equal to 1 — negated. The sums are joined by a product.

For XOR: row 00 → (a + b), row 11 → (a + b):

f(a,b) = (a + b) · (a + b) = Π(0, 3)

💡How not to mix them up

A product must give 1 exactly in its own row → all factors must be ones → the zeros have to be negated. A sum must give 0 exactly in its own row → all terms must be zeros → the ones have to be negated.

Logic diagram

  • A diagram shows the logical structure of a function; information flows from the inputs (left) to the output.
  • A dot where lines cross means a connection; a crossing without a dot means the lines just pass each other.
  • This diagram implements y = (ab + ab) · (a + b + c).

NAND and NOR — universal gates

Logic with four operators (∧, ∨, ⇒, ¬) is redundant — some operators can be expressed through the others. Two are enough: negation + conjunction, or negation + disjunction. And a NAND (or NOR) gate contains both at once, so one kind of gate is enough to build any function.

The second and third rows follow directly from De Morgan's laws.

The essentials of this topic — for a fast recap before the lab.

Logic levels

  • TTL (5 V, bipolar transistors): 0 → 0–0.8 V; 1 → 2–5 V; in between — undefined.
  • CMOS (3–18 V, MOS pairs): 0 → 0–30% of supply; 1 → 70–100%; power only when switching.
  • Hi-Z — the third state (nothing connected); fixed with a pull-up resistor.

Gates

Boolean algebra

  • a + a = 1, a · a = 0, a + ab = a, a(a+b) = a
  • a(b+c) = ab + ac, a + bc = (a+b)(a+c)
  • De Morgan: a + b = a · b, a · b = a + b
  • Combining: ab + ab = a

Canonical forms

  • Sum form (DNF), Σ: from rows with 1; a product of variables, 0 → negated; products joined by "+".
  • Product form (CNF), Π: from rows with 0; a sum of variables, 1 → negated; sums joined by "·".
  • Row number = decimal value of the input bits.

From NAND only

NOT a = a·a; a AND b = a·b; a OR b = a·b

From NOR only

NOT a = a+a; a OR b = a+b; a AND b = a+b
