Lecture 4. Semiconductors: diodes and transistors

Semiconductors

n-typep-type
Dopantdonor, group V (P, As)acceptor, group III (B, Al)
Majority carrierselectronsholes
  • p-n junction: diffusion → recombination → depletion region → potential barrier.
  • Forward: "+" on p (anode), "−" on n (cathode). Reverse: the other way round — no current.

Diode

  • Conducts from anode to cathode once the voltage exceeds the threshold: silicon ≈ 0.6 V; red LED ≈ 2 V ✚.
  • LED: longer lead = anode (+). Always with a resistor: R = Usupply − ULEDI ✚.

Bipolar transistor

  • Terminals: Emitter, Base, Collector. The arrow = emitter. NPN: arrow out, PNP: arrow in.
  • A small base current controls a large collector current: IC = β · IB, β > 100.
  • It turns on when UBE ≈ 0.6 V (B–E junction forward biased).
  • Characteristics: input IB(UBE), output IC(UCE), transfer IC(IB) — linear.
  • As a switch ✚: no base current → cut off (off); large base current → saturated (on).

Field-effect transistors

  • Terminals: S (source), D (drain), G (gate). Controlled by the gate voltage, gate current ≈ 0.
  • JFET: the gate narrows the channel. gm = dIDSdVGS.
  • MOSFET: gate insulated by oxide; the basis of digital circuits (CMOS).

Lecture 5. Operational amplifiers

The op-amp

  • Amplifies the difference: Vout = k · (V+ − V−), k huge (10⁵…10⁷).
  • Ideal: k = ∞, Zin = ∞, Zout = 0, input current 0, offset 0.
  • The output cannot exceed the supply (saturation). Bandwidth × gain = const.
  • ✚ With negative feedback: no current into the inputs, and V+ = V−.

Lecture 6. Digital circuits — introduction: signals, gates, Boolean algebra

Logic levels

  • TTL (5 V, bipolar transistors): 0 → 0–0.8 V; 1 → 2–5 V; in between — undefined.
  • CMOS (3–18 V, MOS pairs): 0 → 0–30% of supply; 1 → 70–100%; power only when switching.
  • Hi-Z — the third state (nothing connected); fixed with a pull-up resistor.

Gates

Boolean algebra

  • a + a = 1, a · a = 0, a + ab = a, a(a+b) = a
  • a(b+c) = ab + ac, a + bc = (a+b)(a+c)
  • De Morgan: a + b = a · b, a · b = a + b
  • Combining: ab + ab = a

Canonical forms

  • Sum form (DNF), Σ: from rows with 1; a product of variables, 0 → negated; products joined by "+".
  • Product form (CNF), Π: from rows with 0; a sum of variables, 1 → negated; sums joined by "·".
  • Row number = decimal value of the input bits.

From NAND only

NOT a = a·a; a AND b = a·b; a OR b = a·b

From NOR only

NOT a = a+a; a OR b = a+b; a AND b = a+b

Lecture 7. Minimisation of Boolean functions: Karnaugh maps

Karnaugh map — the procedure

  1. Draw the map; columns and rows in Gray code: 00, 01, 11, 10.
  2. Fill in the values from the truth table (mind the column order!).
  3. Mark the groups: rectangles of 1, 2, 4, 8 cells; as large as possible, as few as possible; they may overlap; edges and corners touch ✚.

With NAND / NOR

Lecture 8. Combinational functional blocks: multiplexer, two's complement, adder, ALU

Multiplexer

  • n address inputs → 2n data inputs; output = the data input whose number is on the address.
  • Function on a 16:1 MUX: feed 1 to the inputs listed in Σ, 0 to the rest.
  • Function on an 8:1 MUX: 3 variables to the address, the fourth "free" one x. For each address compare y at x = 0 and x = 1:
y(x=0), y(x=1)0, 01, 10, 11, 0
feed the input01xx
  • Free x3: row pairs (k, k+8). Free x0: pairs (2k, 2k+1).
  • DMUX: one input → the output indicated by the address. Decoder: binary → 1 of N.

Two's complement (N bits)

  • Weight of the top bit: −2N−1. Range: −2N−1 … 2N−1−1 (4 bits: −8…7; 8 bits: −128…127).
  • Opposite number: invert the bits, add 1.
  • Add as in plain binary; ignore the carry out of the MSB. Subtraction: a + (−b).
  • Overflow = CIN ⊕ COUT of the top bit (positive + positive = negative, or vice versa).
4-bit U20111000100001111111010011000
value710−1−2−7−8

Adder and ALU

  • Full adder: y = a ⊕ b ⊕ c0, c = ab + ac0 + bc0. An n-bit adder = a cascade.
  • Half adder (no carry in) ✚: s = a ⊕ b, c = ab.
  • ALU: A, B — data; F — operation code; R — result; D — flags. All operations computed at once, a MUX picks the result.
  • Other codes: BCD (digit → 4 bits), ZM (sign bit + magnitude), U1 (bits inverted), Gray, 1 of N.

Lecture 10. Designing synchronous sequential circuits

The procedure (Moore machine, D flip-flops)

  1. States and outputs — write down what the outputs should be in each state.
  2. Graph / transition table — for every state and every combination of inputs: the next state.
  3. Coding — n flip-flops, 2n ≥ number of states; codes best in Gray order (00, 01, 11, 10).
  4. Coded table — replace state names with codes.
  5. Excitation functions — for a D flip-flop: Di = the i-th bit of the next state. Karnaugh map over: state bits + inputs.
  6. Output functions — Karnaugh map over the state variables only (Moore).
  7. Circuit — flip-flops on a common clock + gates.

Remember

  • Moore: output = f(state) — values in the circles. Mealy: output = f(state, input) — values at the arrows.
  • Every state needs an arrow for every combination of inputs.
  • Coding — codes differing in 1 bit for: (1) states with the same next state, (2) next states of the same state, (3) states with the same outputs.
  • Equivalent states: same outputs + next states the same or equivalent → merge into one.
  • Don't-care cells (spare codes, impossible inputs) — fill in whatever is convenient.
  • Handy: XOR = ab + ab; the formulas often simplify to XOR/AND/NOT.

Lecture 11. Computer systems, microprocessors and microcontrollers

The computer

  • Von Neumann: processor (with ALU) + memory (data and program together) + input/output; instructions executed one after another.
  • Harvard: separate program and data memory (microcontrollers: Flash + RAM).
  • Instruction cycle: fetch → decode → execute.
  • Registers: PC (address of the next instruction), instruction register, accumulator, SP (stack), flag register.
  • Buses: address, data, control.
  • CISC: many complex instructions, variable time. RISC: few simple instructions, one cycle, pipelining.

The microcontroller

µC = processor + RAM + program memory + I/O ports + peripherals (UART, SPI, I²C, ADC, timers, watchdog) in one chip.

Programming: high-voltage programmer / ISP / bootloader (Arduino).

Lecture 13. Microcontroller peripherals and event handling

Pins and PWM

  • pinMode(pin, OUTPUT / INPUT / INPUT_PULLUP); max 40 mA per pin; never short an output to ground or supply.
  • PWM: duty cycle ω = τT; average voltage = duty × 5 V. Arduino: analogWrite(pin, 0…255), about 490 Hz.
  • Servo: a pulse every 20 ms (50 Hz); 1.5 ms = neutral position (90°).
  • ADC: 10 bits → 0…1023; U = reading · 51023 ✚. "Analog" output = PWM + filter.

The transistor as a switch

  • Cut-off (no base current) = off; saturation (large base current) = on.
  • H-bridge: S1+S4 → one direction, S2+S3 → the other; speed — PWM.

Converters

  • DAC with weighted resistors: an op-amp as a current summer.
  • Flash ADC: 2n − 1 comparators, very fast, few bits.
  • Successive-approximation ADC: n comparisons for n bits (first with half the range).

Events

PollingInterrupt
the program checks in a loophardware signals, the program is suspended

  • Interrupts: hardware (external, timer, exceptions) and software; maskable / non-maskable (reset).
  • Interrupt vector = the handler's address; PC goes onto the stack.
  • Handling: identify → clear the cause → disable → push registers → handle → pop registers → enable → return.
  • AVR: no priorities (a flat system).
  • Arduino: attachInterrupt(digitalPinToInterrupt(2), function, CHANGE | RISING | FALLING); shared variables: volatile.

Formulas

  • Non-inverting: kU = 1 + R2R1 — output in phase
  • Inverting: kU = R2R1 — output inverted (180°)
  • Measurement: Uin = a · Sa, Uout = b · Sb, kU = UoutUin
  • Offset: U = divisions · sensitivity (mV/div, input grounded)
  • Comparator: V+ > V− → +Vc; otherwise −Vc. Positive offset → high for longer.

Remember

  • R2 = the larger resistor, always in J5. Measure the resistors with the multimeter before plugging them in.
  • Generator: 1 kHz sine, small amplitude (to avoid clipping at ±12 V).
  • Check the module's power and the common ground.

Lab 7. Introduction to digital circuits: Logisim, truth table, gates

Logisim

  • Input = green square, output = green circle, gates in the Gates folder.
  • The hand (Poke) toggles an input 0 ↔ 1; the arrow (Edit) draws wires.
  • Colours: bright green = 1, dark green = 0, blue = not connected, red = conflict.
  • A new circuit: Project → Add Circuit…; then you place it like a gate.
  • Truth table of a circuit: Project → Analyze Circuit. ✚

The design path

  1. Verbal description → truth table (rows in binary: 000, 001, …).
  2. Table → formula: for each one a product of the variables (0 → negated), sum everything.
  3. Formula → schematic: NOT first, then AND, OR last.
  4. Test all combinations.
